The problem

Different models offer different trade-offs between accuracy, latency, and memory use. As workloads change, a serving system needs to choose which model to run and where to keep the alternatives.

The system

Kairos builds on vLLM to connect workload monitoring, model selection, and placement across GPU memory, host memory, and storage. Accuracy and latency targets guide its decisions.

My work

  • Model reconfiguration primitives for sleeping, waking, prefetching, and evicting model weights.
  • A planner that selects models and allocates memory according to workload and service targets.
  • Experiments on reconfiguration costs, model trade-offs, and end-to-end serving behavior.
