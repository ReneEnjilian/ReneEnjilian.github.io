The project

Apache SystemDS is a system for large-scale machine learning and data analysis. Its compiler and runtime translate high-level operations into execution plans across different backends.

My contributions

  • GPU backend modernization and integration with CUDA libraries.
  • Java–CUDA integration through JNI, including cuSPARSE and cuBLAS.
  • Sparse matrix formats and compiler DAG rewrites.

Background

I contributed to SystemDS during my research work at BIFOLD / TU Berlin and became an Apache SystemDS committer.
